# LongMemEval-S release recall run

This is an ignored, opt-in integration benchmark for a pinned 20-case subset of
LongMemEval-S. The checked-in files are the upstream MIT license, the subset
freezer, and its manifest. The 10 MB `input.jsonl` and evaluator-only
`gold.jsonl` stay outside the repository.

The frozen manifest pins upstream revision `98d7416c24c778c2fee6e6f3006e7a073259d48f`,
the 500-row source-file hash, the 20 selected cases, the freezer, both JSONL
hashes, and the verbatim license. The selected subset contains 20 cases and 943
full-history sessions. It has 12 answerable cases and 8 abstention annotations;
the 40% abstention rate describes this selected subset, not the 500 source rows.

Each case gets a fresh temporary SQLite store. Every complete history session is
recorded as one untrusted session episode with its original session ID/date and
all user/assistant turn text, followed by explicit raw-source indexing and
embedding. The runner uses the default read policy and exact token budgets of
2,000 and 3,000. It runs no extraction and no answer reader. Gold is opened only
after all retrieval requests finish.

The output contains the actual selected evidence coordinates, including source
reference, revision, view, byte range, support episode, and response-scoped
citation ID where compact rendering is enabled. It also records each read's
channel receipts, index coverage, execution and truth-selection receipts,
token counts, and elapsed setup/index/embed/read times. Full-history session
selection is reported as descriptive retrieval breadth. Gold turn annotations
are mapped by both session index and exact upstream session ID; byte coverage
measures the whole annotated turn because the labels do not identify minimal
supporting substrings. Answer-session metrics use exact `answer_session_ids`
matches. Unmapped IDs remain unavailable. Abstention labels are never counted
as successful abstentions without a reader, and no string-only answer credit is
computed.

The source dates are stored in their original text form and parsed as UTC only
to preserve deterministic store ordering; the upstream values do not specify a
timezone. This dataset is English-only, uses curated questions, and is not a
multilingual or real-user-dialogue evaluation.

## Reproduce the subset

The freezer fetches the pinned upstream source and license, verifies their
hashes, and writes its outputs beside itself. Run it from a directory outside
the repository so the raw JSONL files remain external:

```sh
mkdir -p /tmp/oxibrain-longmemeval-s-public-v1
cp eval/research/longmemeval-s/freeze_subset.py /tmp/oxibrain-longmemeval-s-public-v1/
cd /tmp/oxibrain-longmemeval-s-public-v1
python3 freeze_subset.py
```

The current frozen artifacts were generated by that script at the pinned
revision. Before a release run, the runner verifies the manifest, freezer,
input, gold, and license SHA-256 values against the committed manifest and
release constants.

## Run default retrieval

Provide explicit paths to the existing local BGE GGUF and exact tokenizer JSON.
The runner does not select a model from ambient configuration or download
weights. It reports both artifacts' BLAKE3 digests; optional expected-digest
variables make a repeat run fail if either artifact changes.

```sh
export OXIBRAIN_RUN_LONGMEMEVAL=1
export OXIBRAIN_LONGMEMEVAL_DIR=/tmp/oxibrain-longmemeval-s-public-v1
export OXIBRAIN_EMBED_MODEL=/absolute/path/to/bge-m3-Q4_K_M.gguf
export OXIBRAIN_TOKENIZER_JSON=/absolute/path/to/tokenizer.json
export OXIBRAIN_LONGMEMEVAL_OUTPUT=/tmp/oxibrain-longmemeval-default.json
# Optional artifact pins, normally copied from a previously reviewed report:
# export OXIBRAIN_LONGMEMEVAL_EXPECT_EMBED_BLAKE3=<64-lowercase-hex>
# export OXIBRAIN_LONGMEMEVAL_EXPECT_TOKENIZER_BLAKE3=<64-lowercase-hex>
cargo test -p oxibrain-cli --test external_recall -- --ignored --exact longmemeval_release_runner
```

To evaluate compact rendering separately, set
`OXIBRAIN_LONGMEMEVAL_RENDER_MODE=compact` and choose a different output path.
This only opts into compact response rendering; the report includes the complete
evidence coordinate map for every selected citation. Unset the variable or set
it to `default` for the production default policy. Run it as a separate report:

```sh
export OXIBRAIN_LONGMEMEVAL_RENDER_MODE=compact
export OXIBRAIN_LONGMEMEVAL_OUTPUT=/tmp/oxibrain-longmemeval-compact.json
cargo test -p oxibrain-cli --test external_recall -- --ignored --exact longmemeval_release_runner
```

The run is local after dataset preparation. It does not call an LLM or score an
answer. The resulting JSON should be retained with the exact model/tokenizer
digests and reviewed alongside channel coverage and source-coordinate receipts.
